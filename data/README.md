# Data

## Raw

`raw/Telco-Customer-Churn.csv` is the IBM Telco Customer Churn dataset (7,043 customers,
21 columns). I pulled it from IBM's public GitHub repository:

https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

The same file is distributed on Kaggle as "Telco Customer Churn" (blastchar). It describes a
fictional telco's customers: demographics, the services each one signed up for, contract and
billing details, and whether the customer left within the last month (`Churn`).

The raw file is committed as-is so the cleaning notebook is reproducible from the exact bytes
I worked with.

## Processed

`processed/telco_clean.csv` is the output of `notebooks/01_data_cleaning.ipynb`. Other
intermediates written under `processed/` are gitignored and are regenerated by running the
notebooks in order.
